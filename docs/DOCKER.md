# Docker Setup

ClaimNova supports containerized deployment using Docker Compose.

## Build

```bash id="1fdphn"
docker compose build
```

## Run

```bash id="0ejnh4"
docker compose up
```

## Stop

```bash id="2d4p8u"
docker compose down
```

Application runs at:

```text id="6zv74j"
http://localhost:3000
```

Environment variables are loaded from:

```text id="fks95w"
.env.local
```
